# Cauchemar sans fin

Projet conçu par : Étienne Ayotte

## Le public cible

- Type de joueur visé : Fonceur et fan d'action
- Catégorie et genre : Action combat
- Le concept en une phrase  : Combats grandioses avec une histoire immersive

## Les mécaniques

- Objectif du jeu : Battre le boss final avec tout les améliorations obtenues durant le jeu. Plusieurs fins possibles     dépendamment des choix dans l'histoire
- Condition de victoire : Battre le boss final pour réveiller la personne tenu dans un coma qui rêvait le jeu et l'histoire
- Condition de défaite : Mourir sans avoir battu le boss final et ne pas être capable de réveiller la personne dans le coma
- Mécanique cœur : Utiliser les gestes spécial des personnages obtenus par les améliorations donnés en battant les vagues d'ennemis
- Mécanique secondaire : Trouver des secrets pour obtenir une fin différente à la fin principale
- Structure : Progressif, difficulté augmente après chaque niveau, choix d'améliorations donné au joueur pour compenser à la difficulté
